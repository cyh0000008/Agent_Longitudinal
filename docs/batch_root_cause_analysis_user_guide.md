# 飞书多维表格批量行车问题原因分析使用说明

适用对象：需要批量分析行车数据问题的测试、数据分析、功能开发同事。

版本：2026-07-27

## 1. 这个功能用来做什么

“批量行车问题原因分析”用于批量处理已经整理到飞书多维表格中的行车问题。

你只需要在表格中提前填好每条问题的描述、数据文件路径和问题类型，然后在飞书群里发送固定指令，布鲁会逐行读取待分析问题，调用本地行车问题原因分析能力，并把结果回写到表格。

当前分析重点是判断：

- 现象是否真实发生，例如重制动、顿挫、低速、跟车距离异常等。
- 算法请求侧是否先发生变化。
- 执行器响应侧是否跟随或异常。
- 如果是请求侧导致，进一步结合前车、Cut-in、曲率限速、SetSpeed 等诱因信号解释为什么会给出该请求。

## 2. 固定唤醒指令

只有下面这条指令会直接触发批量分析：

```text
分析飞书多维表格中的问题
```

在群里可以带上机器人名称，例如：

```text
@布鲁 分析飞书多维表格中的问题
```

为了避免误触发，类似“帮我跑一下表格”“处理多维表格问题”“批量分析问题”这类说法不会直接执行。布鲁只会提示你使用正确固定指令。

## 3. 多维表格需要填写哪些列

| 列名 | 谁填写 | 是否必填 | 说明 |
|---|---|---|---|
| Agent_问题描述 | 使用者 | 必填 | 用自然语言描述问题，例如“高速跟车时出现一次重制动”“ACC 稳速未达到 SetSpeed”。 |
| Agent_h5数据路径 | 使用者/布鲁 | 可留空 | 已填写时直接使用；留空时布鲁会根据车号、车型、日期、时间自动查找 H5 并回填。当前仅支持 `.h5` 文件。 |
| Agent_问题类型 | 使用者 | 必填 | 必须填当前支持的问题类型，见第 4 节。 |
| Agent_问题状态 | 布鲁维护 | 必填 | 只有“待分析”才会被处理；空白不会处理。处理中会写为“分析中”，成功后写为“已分析”，失败后写为“分析失败”。 |
| JIRA链接 | 使用者 | 可选 | 非空时，该待分析行会优先处理；没有该列或为空时保持普通处理顺序。 |
| Agent_结论概要 | 布鲁回写 | 不用填 | 一句话概括原因点或证据缺口，方便在表格列表里快速扫读。 |
| Agent_分析结论 | 布鲁回写 | 不用填 | 完整分析结论，包括现象、请求、响应、诱因证据和下一步建议。 |
| Agent_分析信号图示 | 布鲁回写 | 不用填 | 本次分析生成的信号图附件。 |

可以按业务需要增加其他列，但不要改名或删除上面的 `Agent_` 关键列。如果确实需要调整关键列名，需要同步修改布鲁的批量分析配置。

批量任务只处理 `Agent_问题状态 = 待分析` 的记录。若存在 `JIRA链接` 列，且该列非空，这些待分析记录会优先处理；同一优先级内仍按表格原顺序处理。

## 4. 当前支持的问题类型

`Agent_问题类型` 列建议只填写下面这些值：

| 问题类型 | 主要分析内容 |
|---|---|
| 顿挫 | 关注纵向加速度、驱动/制动请求、执行器响应和目标/限速等诱因是否突变。 |
| 重制动 | 判断是否算法主动给出强减速/制动请求，还是执行器响应异常导致实车重制动。 |
| 误制动 | 判断减速是否缺少合理目标或曲率限速诱因。 |
| 溜车 | 判断静止或低速场景下是否存在车辆反向移动，以及制动/驱动响应是否足够。 |
| 稳速未达 Setspeed | 判断未达到设定车速是目标约束、限速、请求侧限制还是执行器未响应导致。 |
| 不合理低速 | 判断低速是否由前车/Cut-in、曲率限速、SetSpeed 变化或执行器响应导致。 |
| 跟车距离 | 判断跟车过近、过远、距离波动及其可能诱因。 |
| 功能退出 | 分析 ACC/LCC 功能退出原因，当前基于配置表中的功能状态和退出原因信号；会识别强激活态降级，以及带原因码的非 OFF 状态退到 OFF。 |

说明：

- 当前所有问题类型都仅支持 `.h5` 数据文件。
- 如果手头数据是 `.blf`、`.hdf5` 或其他格式，请先转换为布鲁可读取的标准 `.h5` 文件，再填写到多维表格。

## 5. Agent_h5数据路径怎么填

`Agent_h5数据路径` 指的是布鲁运行机器或数据组服务器能直接访问到的文件路径，不是你自己电脑上的本地路径。

正确示例：

```text
D:\adas_data\VC9\VC9_ver0520_2026-06-29_21_19_48_CAN_parsed.h5
```

或在 Linux 服务器上：

```text
/data/adas/VC9/VC9_ver0520_2026-06-29_21_19_48_CAN_parsed.h5
```

常见错误：

```text
C:\Users\张三\Downloads\xxx.h5
```

如果这个路径只存在于张三自己的电脑上，布鲁所在服务器无法访问，就会提示“未找到文件”。

```text
xxx.h5
```

只写文件名也不行。程序不会在服务器上按文件名自动搜索。

建议做法：

1. 先把数据文件放到数据组服务器上的固定目录。
2. 在多维表格中填写完整绝对路径。
3. 如果要重跑同一条问题，把 `Agent_问题状态` 改回 `待分析`。

## 6. 使用流程

1. 打开批量分析多维表格。
2. 每一行填写 `Agent_问题描述`、`Agent_h5数据路径`、`Agent_问题类型`。
3. 确认 `Agent_问题状态` 为 `待分析`。
4. 在布鲁所在飞书群发送：

```text
@布鲁 分析飞书多维表格中的问题
```

5. 布鲁会在群里显示处理进度，包括总问题数、已处理数量和当前正在处理的问题。
6. 分析完成后，到多维表格查看：
   - `Agent_问题状态`
   - `Agent_结论概要`
   - `Agent_分析结论`
   - `Agent_分析信号图示`

## 7. 进度和状态说明

| Agent_问题状态 | 含义 |
|---|---|
| 待分析 | 等待布鲁处理。 |
| 分析中 | 布鲁正在处理该行。 |
| 已分析 | 已完成，结果已写入表格。 |
| 分析失败 | 该行处理失败，需要查看失败原因并修正后重跑。 |

批量任务只处理 `Agent_问题状态` 为 `待分析` 的记录。空白、`已分析`、`分析中`、`分析失败` 的记录不会自动覆盖。

## 8. 结果怎么看

`Agent_结论概要` 是最重要的速览列，通常会写成一句明确的话，例如：

- 重制动更像是控制请求先变化，执行器基本是在跟随。
- 误制动更像是前车、限速或交通场景先触发，算法随后给出控制请求。
- 执行器没有跟上控制请求，原因更偏向响应侧。
- 缺少控制请求证据，暂不能判断是不是算法主动要求。

这列面向路试人员快速扫读，不会写具体信号名、内部字段名或规则名。具体信号、时间点和证据链请看 `Agent_分析结论`。

`Agent_分析结论` 会更完整，通常包含：

- 问题是否成立。
- 现象层证据。
- 算法请求侧证据。
- 执行器响应侧证据。
- 前车、Cut-in、曲率限速、SetSpeed 等诱因侧证据。
- 当前能下的结论和下一步建议。

`Agent_分析信号图示` 会放本次分析生成的时序图，方便你核对关键时间点。

## 9. 失败时怎么处理

常见失败原因和处理方式：

| 失败提示 | 常见原因 | 处理方式 |
|---|---|---|
| 未找到数据文件 | `Agent_h5数据路径` 填的是个人电脑路径、相对路径或文件名。 | 改成数据组服务器上的绝对路径。 |
| 缺少 Agent_h5数据路径 | 表格该列为空。 | 补充完整路径。 |
| Agent_问题类型不在范围内 | `Agent_问题类型` 填了未支持的名称或错别字。 | 改成第 4 节中的标准问题类型。 |
| 文件格式不支持 | 当前行车问题原因分析仅支持 `.h5` 文件。 | 先将数据转换为标准 `.h5` 文件，再填写服务器绝对路径。 |
| 关键证据不足 | H5 中缺少请求侧、响应侧或诱因侧关键总线信号。 | 补充包含对应信号的数据，再重新分析。 |
| 功能退出无法分析 | 功能退出所需 debug 状态或退出原因信号缺失。 | 确认 H5 是否包含 ACC/LCC 功能状态和退出原因信号。 |

修正后，把该行 `Agent_问题状态` 改回 `待分析`，再次发送固定指令即可重跑。

## 10. 推荐填写示例

| Agent_问题描述 | Agent_h5数据路径 | Agent_问题类型 | Agent_问题状态 |
|---|---|---|---|
| 6603s 附近出现一次重制动，想确认是算法请求还是执行器响应导致。 | `D:\adas_data\case_001.h5` | 重制动 | 待分析 |
| 稳定跟车时车距明显偏远，想看是否目标或时距设置导致。 | `D:\adas_data\case_002.h5` | 跟车距离 | 待分析 |
| ACC 运行中突然退出，想确认退出原因。 | `D:\adas_data\case_003.h5` | 功能退出 | 待分析 |

## 11. 使用注意事项

- 一次批量任务可能处理多条记录，建议先小批量验证，再放大量问题。
- `Agent_问题描述` 写得越具体，结论越容易聚焦。例如写清楚“重制动”“跟车距离过远”“未达到 SetSpeed”“ACC 退出”等。
- `Agent_h5数据路径` 必须是数据组服务器路径。如果文件还在个人电脑上，请先上传或同步到服务器。
- 不要手动填写 `Agent_分析结论` 和 `Agent_分析信号图示`，这两列由布鲁回写。
- 如果要重跑一条已完成记录，请只把该行 `Agent_问题状态` 改回 `待分析`，不用清空结论。
- 如果多次失败，优先检查路径是否可访问、问题类型是否标准、H5 是否包含关键总线信号。
