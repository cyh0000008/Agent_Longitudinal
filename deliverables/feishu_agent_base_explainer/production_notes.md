# 飞书 Agent 批量分析介绍视频制作说明

## 成片规格

- V1 时长：68 秒
- V2 时长：约 80 秒，缩短串场并增加完整流程和原因样例
- 画幅：1920 × 1080，16:9
- 编码：H.264 / yuv420p
- 帧率：15 fps
- 音频：无，采用片内中文字幕讲解

## 内容结构

1. 路试问题进入真实 Base
2. 逐字段填写问题描述、车型、日期时间、问题类型和待分析状态
3. 在真实布鲁Mate会话中发送固定指令
4. 校验 H5 时间覆盖，必要时自动查找 H5 或从 BLF 解析
5. 现象、算法请求、场景诱因、执行器响应四层证据链
6. 误制动样例：Cut-in 目标误触发最大制动
7. 功能退出样例：驾驶员接管或方向盘转角抑制
8. 车道过窄、算法主动请求和证据不足样例
9. 真实信号窗口验证
10. 群内结果卡片返回摘要
11. 状态、结论概要、完整结论和图示回写 Base

## 图像生成方式

使用 Codex 内置 imagegen 工具，未使用 CLI/API fallback。

### 片头主视觉提示词摘要

企业科技风 16:9 画面，以聊天界面、多维表格、ADAS 遥测、AI 分析核心和诊断报告组成从左到右的数据工作流。深蓝、青色和绿色配色，不生成可读文字、品牌 Logo 或水印，为后续中文字幕留出安全区。

### Base 界面处理提示词摘要

以真实飞书 Base 截图为编辑目标，保留表格布局、字段结构、状态标签及中文标题；仅对个人信息和精确标识做匿名化处理，不重设计界面，不新增字段和记录。

### 布鲁Mate 界面处理提示词摘要

以真实飞书机器人会话截图为编辑目标，保留固定指令、批量分析结果卡片、统计信息和结果表格；模糊左侧无关会话、联系人和组织内部内容，不新增消息或指标。
